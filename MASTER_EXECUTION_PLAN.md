CURRENT OBJECTIVE
Build a world-class enterprise frontend that showcases the backend capabilities without changing backend contracts.

RULES
- Never modify backend without explicit approval.
- Never change API contracts.
- Use existing endpoints only.
- Reuse components before creating new ones.
- Build mobile-first but optimize for desktop demos.
- Every animation must communicate state or progression.
