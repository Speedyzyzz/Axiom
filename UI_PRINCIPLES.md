# UI Interaction Principles

This prevents AI-generated "Dribbble syndrome".

- Animation exists to communicate.
- Cards never bounce.
- Buttons never pulse forever.
- Graphs animate once.
- Timeline reveals chronologically.
- Numbers count once.
- Hover elevation <4px.

## Transitions
- Duration: 200-400ms
- Easing: Always `ease-out`
- Never animate layout unless intentional.
